# 容器页面重设计 v3 Spec

## Why
用户提供了三张草稿图，要求按照图中的布局和样式进行还原并美化：
- 图1（页面）：顶部黑色横幅区域 + 标题区 + 分类标签 + 5列卡片网格
- 图2（卡片）：封面图（大矩形）+ 容器名 + 评分 + 安装量 + 分类标签行
- 图3（弹窗）：头部（图标+名称+作者+安装按钮）+ 简述 + 预览图 + Tab切换（说明/功能介绍/使用教程/更新日志/其他信息）+ 内容区

当前实现与草稿图差异较大，需要完全按照用户提供的布局重新设计。

## What Changes
- **页面顶部横幅**：新增深色渐变横幅区域，包含标题"容器"和右侧操作按钮（上传容器/我的）
- **分类筛选栏**：黑色圆角药片按钮，选中态白色文字黑色背景，右侧"筛选"按钮
- **卡片改为网格布局**：5列网格，大封面图（16:10比例）+ 下方信息区
- **卡片内容**：封面图 + 容器名（左）+ 评分/安装量（右）+ 分类标签行（底部）
- **弹窗改为Tab切换式**：头部保持图标+名称+作者+安装按钮，下方5个Tab（说明/功能介绍/使用教程/更新日志/其他信息），点击切换内容区
- **弹窗内容按Tab组织**：每个Tab展示对应内容，而非全部堆叠展示

## Impact
- Affected code: `src/components/ContainerPage.tsx`（全部重写）、`src/i18n/index.ts`（新增翻译键）

## MODIFIED Requirements

### Requirement: 页面顶部横幅
页面顶部 SHALL 有一个深色渐变横幅区域：
- 高度约 120px，背景为深色渐变（#1a1a2e → #16213e）
- 左侧：橙色圆角方形图标（40px）+ "容器" 大标题（28px，白色，700字重）
- 标题下方：简述文字（14px，白色/0.7透明度）
- 右侧："上传容器"和"我的"两个黑色圆角按钮（白色文字）

### Requirement: 分类筛选栏
横幅下方 SHALL 有分类筛选栏：
- 左侧：4个分类药片按钮（黑色背景、白色文字、圆角9999px）
- 右侧："筛选"按钮（同样黑色药片样式）
- 按钮间距 12px
- 当前选中的分类按钮有白色边框高亮

### Requirement: 卡片网格布局
卡片 SHALL 以 5列网格 展示：
- gridTemplateColumns: 'repeat(5, 1fr)'
- 间距 gap: 20px
- 页面最大宽度 1400px，居中

### Requirement: 卡片样式
每张卡片 SHALL 包含：
- **封面区**：宽高比 16:10，圆角 12px，背景为 item 的渐变色，内部居中显示大图标（48px）
- **信息区**（封面下方，padding 10px 0）：
  - 第1行：flex between，左侧容器名（14px，600），右侧评分（⭐ + 数字）和安装量
  - 第2行：分类标签行，黑色圆角药片（小号，12px）
- **悬停**：封面区亮度微增，整体 translateY(-4px)，阴影加深

### Requirement: 弹窗头部
弹窗头部 SHALL 包含：
- 左侧：48px 圆角方形渐变图标
- 中间：容器名（22px，700）+ 作者（13px，灰色）
- 右侧："安装"按钮（黑色背景，白色文字，圆角 8px）
- 关闭按钮（右上角 X）

### Requirement: 弹窗Tab切换
弹窗 SHALL 有5个Tab按钮横向排列：
- Tab列表：说明 / 功能介绍 / 使用教程 / 更新日志 / 其他信息
- 选中态：底部 2px 黑色下划线，文字加粗
- 未选中态：灰色文字
- 点击切换下方内容区

### Requirement: Tab内容区
- **说明Tab**：展示 detailedDescription 文本
- **功能介绍Tab**：展示 features 列表（绿色对勾）
- **使用教程Tab**：展示 usageGuide 步骤（编号圆圈 + 标题 + 说明）
- **更新日志Tab**：展示 changelog 时间线
- **其他信息Tab**：展示信息面板（版本/开发者/上架时间/最近更新/安装量/场景）

### Requirement: 弹窗预览区
弹窗头部下方、Tab上方 SHALL 有预览区：
- "预览" 标题
- 横向滚动的截图卡片（圆角，浅色背景）
- 如果有视频则显示视频预览卡片（深色背景 + ▶）
