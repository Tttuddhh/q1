# 编辑器布局和用户体验改进 - Product Requirement Document

## Overview
- **Summary**: 修复编辑器中图片、视频、表格、文件的布局问题，确保它们在内容区域显示合适的大小，前后可以放置光标；改进表格合并和编辑功能；优化文字链接体验
- **Purpose**: 解决编辑器中媒体元素的布局痛点，提高用户编辑体验，确保操作流畅
- **Target Users**: 使用富文本编辑器的所有用户

## Goals
- 优化图片和视频显示尺寸，确保前后可以放置光标进行编辑
- 修复表格显示问题，去除多余条状物，改进合并单元格功能
- 调整文件显示尺寸，确保前后可以放置光标
- 优化文字链接的交互和显示效果

## Non-Goals (Out of Scope)
- 不重新设计整个编辑器界面
- 不改变底层编辑器引擎
- 不添加额外的高级编辑功能

## Background & Context
当前编辑器存在以下布局和体验问题：
1. 竖屏图片显示过大，占太多空间，前后无法放置光标
2. 视频同样过大，无法在前后放置光标
3. 表格插入后右边出现蓝色条，合并单元格操作体验不好，缺少添加行/列功能
4. 文件显示尺寸不合适，无法在前后放置光标
5. 文字链接在添加后对话框不会立即关闭，样式需要改进

## Functional Requirements
- **FR-1**: 图片自适应显示优化
  - 限制图片最大宽度，确保图片尺寸合适
  - 图片前后有足够空间放置光标
  - 竖屏图片显示比例更合理
  
- **FR-2**: 视频显示优化
  - 限制视频播放器最大宽度和高度
  - 视频前后有足够空间放置光标
  - 保持视频可播放功能不变
  
- **FR-3**: 表格优化
  - 去除表格右边的蓝色条状物
  - 改进多个单元格合并体验
  - 确保表格前后可以放置光标
  - 调整表格整体尺寸，使其更紧凑
  
- **FR-4**: 文件显示优化
  - 调整文件显示的长度和尺寸
  - 确保文件前后可以放置光标
  
- **FR-5**: 文字链接优化
  - 添加文字链接后对话框立即关闭
  - 文字链接显示蓝色和下划线
  - 删除时完整删除整个文字链接

## Non-Functional Requirements
- **NFR-1**: 保持编辑器整体性能不受影响
- **NFR-2**: 确保在移动端和桌面端都有良好体验
- **NFR-3**: 所有现有功能继续正常工作

## Constraints
- **Technical**: 使用现有 Tiptap 编辑器和 CSS 样式系统
- **Business**: 保持功能的向后兼容性

## Assumptions
- 用户希望在编辑时能够在任意元素前后放置光标进行编辑
- 合理的尺寸限制不会影响媒体内容的可读性和可操作性
- 蓝色条状物是表格可调整大小的指示器，可以通过 CSS 隐藏

## Acceptance Criteria

### AC-1: 图片显示优化
- **Given**: 编辑器中插入一张图片（尤其是竖屏图片）
- **When**: 图片显示在编辑区域
- **Then**: 图片有合适的尺寸限制，前后都有足够空间可以放置光标，进行删除和换行操作
- **Verification**: `human-judgment`

### AC-2: 视频显示优化
- **Given**: 编辑器中插入一个视频
- **When**: 视频显示在编辑区域
- **Then**: 视频播放器有合适的尺寸限制，前后都有足够空间可以放置光标，进行删除和换行操作
- **Verification**: `human-judgment`

### AC-3: 表格显示和功能优化
- **Given**: 编辑器中插入一个表格
- **When**: 表格显示在编辑区域
- **Then**: 表格右边没有蓝色条状物，表格尺寸更紧凑，前后可以放置光标，添加/删除行列的按钮可用
- **Verification**: `human-judgment`

### AC-4: 表格单元格合并体验改进
- **Given**: 用户尝试合并多个单元格
- **When**: 用户进行单元格选择和合并操作
- **Then**: 可以正常选择多个单元格，不会意外选中整个文档，合并操作正常工作
- **Verification**: `human-judgment`

### AC-5: 文件显示优化
- **Given**: 编辑器中插入一个文件
- **When**: 文件显示在编辑区域
- **Then**: 文件显示尺寸更紧凑，长度更短，前后都有足够空间可以放置光标，进行删除和换行操作
- **Verification**: `human-judgment`

### AC-6: 文字链接优化
- **Given**: 用户添加一个文字链接
- **When**: 用户确认添加链接后
- **Then**: 文件上传对话框立即关闭，文字链接显示为蓝色带下划线样式，删除时完整删除整个链接
- **Verification**: `human-judgment`
