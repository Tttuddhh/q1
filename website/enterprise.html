关于企业合作的常见疑问解答

是的，企业版支持私有化部署。你可以将橙光笔录部署在自己的服务器或私有云环境中，确保数据完全由企业掌控，满足合规和安全要求。

团队版适合小型团队使用，提供协作空间、全文搜索和优先支持等功能。企业版在团队版基础上增加了 SSO 单点登录、私有化部署、专属客户经理和 SLA 保障等企业级功能，更适合大型组织的复杂需求。

我们提供完善的数据迁移方案，支持从 Notion、Confluence、语雀等主流知识库工具导入数据。企业版客户还可获得专属迁移顾问的一对一支持，确保数据平稳过渡。

橙光笔录提供丰富的 API 和 Webhook 支持，可与 Slack、钉钉、飞书、Jira、GitHub 等常用工具无缝集成。企业版还可根据需求定制专属集成方案。

个人版用户可通过社区论坛获得支持。团队版用户享有优先工单响应。企业版客户配备专属客户经理，提供 7×24 小时技术支持，并签署 SLA 服务保障协议。
